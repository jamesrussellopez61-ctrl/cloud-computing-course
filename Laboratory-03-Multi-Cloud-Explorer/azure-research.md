# Microsoft Azure Research & Platform Overview

## Brief Overview
Microsoft Azure is a leading public cloud computing platform providing Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS). Launched in 2010, it is deeply integrated with Microsoft’s enterprise software software ecosystem.

## Global Infrastructure
Azure has a vast global footprint designed to support enterprise residency requirements:
* **Regions**: Azure spans 70+ regions globally, grouped into geographies.
* **Availability Zones**: Physically separate data center locations within a region with independent power and networking.
* **Region Pairs**: Most Azure regions are paired with another region within the same geography for cross-region disaster recovery.

## Cloud Management Console
The **Azure Portal** is a unified, browser-based console for building, managing, and monitoring all Azure cloud resources. It features customizable dashboards, integrated Azure Cloud Shell, and seamless access to resource management tools.

## Core Services
1. **Compute**: **Azure Virtual Machines** – On-demand Linux and Windows VM infrastructure.
2. **Storage**: **Azure Blob Storage** – Massive object storage for unstructured data.
3. **Database**: **Azure SQL Database** – Fully managed relational database engine based on Microsoft SQL Server.
4. **Networking**: **Azure Virtual Network (VNet)** – Private cloud network isolation and hybrid connection.

## Key Advantages
* **Seamless Microsoft Integration**: Native support for Active Directory (Entra ID), Office 365, and Windows Server.
* **Hybrid Cloud Dominance**: Strong hybrid solutions with Azure Arc and Azure Stack.
* **Enterprise Licensing Benefits**: Cost savings when transferring existing Windows Server and SQL licenses.

## Enterprise Use Cases
* **Enterprise ERP & Active Directory**: Migrating corporate Windows infrastructure and Active Directory domain services to the cloud.
* **Hybrid Application Deployment**: Connecting on-premises data centers directly to Azure cloud environments.
