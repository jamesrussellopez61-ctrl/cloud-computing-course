# Lab 03 Reflection: Business-Driven Cloud Selection

Completing Laboratory 03 has provided valuable insight into how modern organizations evaluate, select, and deploy infrastructure across public cloud platforms. Rather than viewing AWS, Microsoft Azure, and Google Cloud Platform purely as technical service catalogs, this project highlighted how cloud choices are fundamentally driven by strategic business needs, financial models, and existing enterprise software footprints.

Throughout this research, I discovered that no single cloud provider is universally "superior." Instead, each platform has cultivated distinct market strengths. Amazon Web Services stands out for its sheer size, service depth, and first-mover maturity, making it an ideal default for rapid startup scaling and versatile workloads. Microsoft Azure dominates the traditional enterprise landscape due to its seamless compatibility with Windows Server and Active Directory ecosystems, providing significant cost advantages through existing license portability. Meanwhile, Google Cloud Platform leads in high-performance data analytics, machine learning, and container orchestration with native Kubernetes support.

Understanding these distinctions is essential when formulating client-specific recommendations. A multi-cloud or hybrid-cloud strategy allows businesses to leverage best-of-breed tools—such as using Azure for enterprise identity management while hosting machine learning models on GCP's Vertex AI—while mitigating vendor lock-in and improving fault tolerance.

Technically, investigating the Linux environment via KillerCoda reinforced how compute resources operate identically under the hood, regardless of which cloud vendor hosts the virtual server. Mastering markdown documentation on GitHub has also improved my ability to present technical evaluations in a clean, professional, and structured format. Moving forward in my cloud computing journey, I feel better equipped to analyze organizational requirements and align them with the optimal cloud architecture.
