# Lab 03 Reflection: Choosing the Right Cloud Platform

Completing Lab 03 gave me a solid understanding of how companies actually choose and use cloud platforms. Instead of seeing AWS, Azure, and GCP as just lists of technical features, I learned that picking a cloud platform comes down to real business needs, costs, and whatever software a company is already using.

One big takeaway for me is that there is no single best cloud provider for everything. Each one has its own strengths. Amazon Web Services is huge and has been around the longest, which makes it a safe pick for startups that need to scale quickly. Microsoft Azure is the go to choice for big companies that already rely heavily on Windows and Active Directory because it links up easily and saves money on licenses. Google Cloud Platform is the clear winner when it comes to big data, artificial intelligence, and working with containers like Kubernetes.

Knowing these differences makes it much easier to give smart recommendations to clients. Many businesses actually use a mix of clouds so they can get the best tools for each job, like using Azure for user accounts while running machine learning models on GCP, which also keeps them from getting stuck with just one vendor.

Working in the Linux terminal on KillerCoda showed me that virtual servers work the exact same way underneath, no matter which company is hosting them. Formatting everything in Markdown on GitHub also helped me learn how to present technical information cleanly. Overall, this lab helped me see how cloud technology fits into real world business decisions.
