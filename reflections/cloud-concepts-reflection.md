                       Personal Reflection: Everyday Cloud Apps and Why Version Control Matters

Cloud computing is a huge part of my daily life, even when I don't realize it. It powers so many of the apps I 
use every single day for school, entertainment, and talking to friends. Three cloud apps I use all the 
time are Google Drive, Canva, and GCash.

First, Google Drive is a Software as a Service (SaaS) running on a Public Cloud. It lets me save my files and work
on homework with classmates in real-time, without having to worry about how the servers actually work behind the scenes. 
Second, Canva is also a Software as a Service (SaaS) on a Public Cloud. I use it to design graphics right in my web browser 
using tools and templates hosted online. Third, GCash is Software as a Service (SaaS) that uses a secure Hybrid/Public Cloud. 
It lets me send money and pay for things instantly on my phone while keeping my transaction data safe and fast.

Besides the everyday apps we use, tools like Git and GitHub are super important for managing cloud projects. Today, cloud setups a
re written and managed using code. If you change something live on a cloud server without keeping track of it, you could accidentally 
crash a website or break an app.

GitHub acts like a giant, shared save-game for coders. It lets team members work on the same project at the same time without ruining 
each other's work. If someone makes a mistake or breaks the code, version control lets the team see exactly who made the change, 
figure out what went wrong, and instantly undo the mistake. Using the cloud together with version control makes building apps safer, 
faster, and much easier for everyone.
